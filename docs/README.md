# 织灵文档

当前开发与验收以以下文件为准：

- [需求基线](product-baseline.md)：完整产品范围与核心约束。
- [实现与验收](acceptance.md)：已实现、待实现及实际验收状态。
- [发布检查清单](测试清单.md)：安装包、账号、服务、数据和桌面体验的检查条件。
- [验证记录](verification.md)：本工程实际执行的自动检查及其边界。
- [Agent 任务](agent-guide.md)：引擎安装、任务通道与权限配置。

`superpowers/` 是随代码历史保留的早期设计资料，不是织灵的产品需求、当前架构或功能验收依据。遇到其中的固定角色、旧应用名称或旧账号配置时，不得据此恢复预设人格或改变当前产品方向。

面向开发 Agent 的入口为根目录 `AGENTS.md`。组件许可与版权记录在根目录 `THIRD_PARTY_NOTICES.md`。
