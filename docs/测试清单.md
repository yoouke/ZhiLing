# 织灵发布检查清单

这是产品交付检查，不能用自动测试数量代替。每项记录版本、系统、操作、结果和失败日志；未执行项标记「未验收」。

| 范围 | 操作与验收结果 |
| --- | --- |
| 产品命名 | 仓库介绍、窗口、安装器、快捷方式、托盘、后台默认账号、生成配置均使用织灵名称；不出现旧产品安装入口 |
| 安装内容 | 安装包不附带固定人设和旧角色声音示例；组件署名、许可证完整；用户可导入自己的角色 |
| 空环境 | Win10/11 x64 无 Python/Node 环境安装，应用自动准备依赖，不要求手工连接另一个产品 |
| 断点恢复 | 中途断网或关闭窗口后可继续，已填资料和有效授权保留；下载与解压失败有明确提示 |
| 账号与身份 | 协议端账号和主人身份分开，扫码登录可恢复，失效时重新验证；仅主人可执行管理操作 |
| 协议端选择 | 同一 QQ 通道 NapCat / SnowLuma 二选一，未选中的端不安装、不启动；许可不允许时提供已有端检测 |
| 角色创建 | AI 引导讨论、提示词导入、联网创作三条路径分别运行；官方、二创、社区内容有区分及来源 |
| 多角色 | 角色的身份、记忆、知识、语音、插件、会话和账号互相隔离；切换与重启不串用数据 |
| 任务链路 | 平台发任务 → Agent 执行工具 → 原通道收到结果；图片、附件及审批正常往返 |
| 插件 | 真实安装、启停、配置、更新、卸载；缺失或不兼容有提示；各角色权限独立生效 |
| 日常能力 | 文字、表情、语音、唱歌、记忆、主动聊天等使用真实账号和服务分别验证 |
| 平台 | 每种通信平台分别登录、收发与恢复；内容平台仅在授权范围内操作 |
| 权限与隐私 | 普通用户无法取得主人记忆或使用电脑工具；提示词和角色好感不能提升系统权限 |
| 监控 | 请求、Token、模型、角色、插件及费用统计区分实际与估算；资源和服务状态准确 |
| 桌面行为 | 独立窗口、托盘、关窗后台、自启动、单实例、启动/停止/重启和异常恢复符合设置 |
| 自定义 | 主题、UI、图标、角色资源可导入和恢复；失败不会让应用无法启动 |
| 更新与卸载 | 更新保留用户资料；卸载范围和备份说明明确，避免删除其他账号或其他程序的数据 |
| 发布 | Windows 安装包可下载，校验值及说明齐全；仓库状态与真实验收结果一致 |

当前实现与未完成项以 [验收清单](acceptance.md) 为准；自动检查证据见 [验证记录](verification.md)。
