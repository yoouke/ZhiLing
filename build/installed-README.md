# 织灵 · ZhiLing

Windows 本地 AI 虚拟人格应用 · 开发预览

## 开始使用

通过织灵窗口选择安装位置、填写所需 API 配置、创建角色并扫码连接 QQ。角色设定由你填写，可以直接粘贴提示词或导入 Markdown/TXT 文档。程序不附带固定人格。

安装中断后重新打开织灵，选择相同位置继续。安装完成后使用桌面的「启动织灵」入口；服务启停、修改配置、登录恢复和 Agent 任务均从程序操作。

「Agent 任务」可准备独立的 DSH 运行环境。日常交流与任务通道分开；实际模型调用需要你自己的 API 授权。

## 数据与维护

不要将安装目录、state.json、服务配置、聊天记录或账号登录缓存直接公开分享。更新与卸载前请备份重要角色资料和记忆。遇到故障时先查看界面提示与 logs 目录，分享日志前检查其中是否有私人信息。

## 当前范围

本版本为开发预览。多人格运行隔离、AI 讨论与联网创作、协议端选择、多平台统一管理、完整监控及 DIY 仍在建设中。自动化启动检查不代表真实 QQ、模型、语音授权或 Win10/11 桌面完整流程已经验收。
